# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of **Custom Agent AGY** seriously. If you discover a security vulnerability (such as a prompt injection risk, credential leakage risk, or arbitrary execution risk in system prompts):

1. **Do NOT open a public GitHub issue.**
2. Email the maintainer directly or submit a private security advisory via GitHub Security tab.
3. Provide details including:
   - Agent prompt name
   - Reproduction steps
   - Potential impact
4. We will respond within 48 hours and work with you to release a patch promptly.

Thank you for keeping our community safe!
